# Learnings

Inbox of non-obvious lessons from agent sessions. Not loaded automatically: the agent reads the entries whose scope matches the task. Entries that repeat get promoted to AGENTS.md, `.claude/rules/`, a skill, or a hook, and are then removed from this file.

Entry format:

```
- **[scope: <glob or area>]** <what to do or avoid, concrete enough to act on cold>.
  _Why:_ <cause>. _Seen:_ <YYYY-MM-DD> ×<count>
```
